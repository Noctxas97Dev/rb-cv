# Raúl Bleda Martínez — Portfolio

Personal portfolio, updated from the CV supplied by Raúl in September 2026.

Static HTML, CSS and a small JavaScript enhancement for experience filters. No build step or remote runtime is needed. The photo and fonts are preserved from the previous portfolio; experience details remain usable without JavaScript.

## Preview

```sh
python -m http.server 8000
```

Open `http://localhost:8000`. GitHub Pages serves the root `index.html`.

## Edit

- `index.html`: profile, experience, projects, education and certifications.
- `styles.css`: responsive, keyboard focus and print styles.
- `script.js`: experience filters and print expansion.

The Macquarie University dates are Aug–Sep 2026, with the start year confirmed by Raúl to correct a typo in the source PDF. The original PDF is not included in this public repository. Epic Games authorization and Universal Arts School teaching dates are shown separately.
